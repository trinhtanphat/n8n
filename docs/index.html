1

Đăng nhập / Đăng ký

Truy cập n8n.vnso.vn, đăng nhập bằng email hoặc tạo tài khoản mới.

Click "Test workflow" để chạy thử. Xem output từng node, debug trong editor.

Bật toggle "Active" để workflow chạy tự động. Theo dõi trong tab Executions.

REST API & Webhook

Tích hợp với bất kỳ hệ thống nào qua API

Webhook
REST API
Python
cURL
# Webhook URL format
POST https://n8n.vnso.vn/webhook/<webhook-id>

# Example: Trigger a workflow
curl -X POST https://n8n.vnso.vn/webhook/abc-123 \
  -H "Content-Type: application/json" \
  -d '{"event":"new_order","customer":"Nguyen Van A","amount":500000}'
# List workflows
GET https://n8n.vnso.vn/api/v1/workflows
Headers: X-N8N-API-KEY: your-api-key

# Execute workflow
POST https://n8n.vnso.vn/api/v1/workflows/{id}/execute
Body: {"data":{"key":"value"}}

# Get execution
GET https://n8n.vnso.vn/api/v1/executions/{executionId}
import requests

# Trigger via webhook
resp = requests.post(
    "https://n8n.vnso.vn/webhook/abc-123",
    json={"event": "process_doc", "file_url": "https://example.com/doc.pdf"}
)
print(resp.json())

# REST API
headers = {"X-N8N-API-KEY": "your-api-key"}
workflows = requests.get(
    "https://n8n.vnso.vn/api/v1/workflows", headers=headers
).json()
# List workflows
curl -s https://n8n.vnso.vn/api/v1/workflows \
  -H "X-N8N-API-KEY: your-api-key" | python3 -m json.tool

# Activate workflow
curl -X PATCH https://n8n.vnso.vn/api/v1/workflows/{id} \
  -H "X-N8N-API-KEY: your-api-key" \
  -d '{"active":true}'

Hướng dẫn sử dụng

Bắt đầu tạo workflow tự động chỉ trong vài phút

Đăng nhập hệ thống

Truy cập https://n8n.vnso.vn và đăng nhập bằng tài khoản được cấp. Lần đầu đăng nhập sẽ thiết lập tài khoản admin.

Tạo Workflow mới

Nhấn nút "+" hoặc vào Workflows → New Workflow. Đặt tên mô tả cho workflow.

Thêm Node đầu tiên

Click "+" trên canvas, chọn Trigger node (VD: Schedule Trigger, Webhook). Mỗi workflow cần ít nhất 1 trigger.

Kết nối các Node

Thêm các node xử lý tiếp theo. Kéo đường nối từ output sang input. VD: HTTP Request → Google Sheets.

Cấu hình Credentials

Vào Settings → Credentials để thêm API key, OAuth token. N8N mã hóa và lưu trữ an toàn.

Test & Kích hoạt

Nhấn "Test Workflow" để chạy thử. Khi ổn, bật Active toggle để workflow chạy tự động.

Các loại Node phổ biến

🟢 Trigger Nodes

Schedule Trigger — Chạy theo lịch (mỗi phút/giờ/ngày)
Webhook — Nhận dữ liệu từ bên ngoài
Email Trigger — Khi có email mới

🔵 Action Nodes

HTTP Request — Gọi API bất kỳ
Send Email — Gửi email tự động
Google Sheets — Đọc/ghi spreadsheet

🟡 Logic Nodes

IF — Rẽ nhánh theo điều kiện
Switch — Nhiều nhánh điều kiện
Merge — Gộp dữ liệu từ nhiều nguồn

Ứng dụng thực tế

Một số workflow mẫu cho doanh nghiệp

📧 Tự động gửi báo cáo

  • Schedule Trigger (hàng ngày 8:00)
  • HTTP Request → lấy dữ liệu từ API
  • Function → xử lý, tổng hợp
  • Send Email → gửi cho quản lý

💬 Chatbot Telegram

  • Telegram Trigger → nhận tin nhắn
  • Switch → phân loại nội dung
  • HTTP Request → gọi AI API
  • Telegram → trả lời tự động

📋 Đồng bộ dữ liệu

  • Webhook → nhận từ hệ thống ERP
  • IF → kiểm tra dữ liệu hợp lệ
  • MySQL → cập nhật database
  • Slack → thông báo kết quả

📁 Xử lý file tự động

  • Google Drive Trigger → file mới
  • Function → đổi tên, phân loại
  • Move file → thư mục đích
  • Email → thông báo hoàn tất

Webhook & API

Tích hợp N8N với hệ thống bên ngoài qua Webhook

Tạo Webhook nhận dữ liệu

# Gửi dữ liệu đến webhook N8N
curl -X POST https://n8n.vnso.vn/webhook/your-webhook-id \
  -H "Content-Type: application/json" \
  -d '{
    "name": "Nguyen Van A",
    "email": "a@vnso.vn",
    "action": "new_order"
  }'

Sử dụng N8N REST API

# Liệt kê tất cả workflows
curl -X GET https://n8n.vnso.vn/api/v1/workflows \
  -H "X-N8N-API-KEY: your-api-key"

# Kích hoạt workflow
curl -X PATCH https://n8n.vnso.vn/api/v1/workflows/{id}/activate \
  -H "X-N8N-API-KEY: your-api-key"

# Lấy lịch sử thực thi
curl -X GET https://n8n.vnso.vn/api/v1/executions \
  -H "X-N8N-API-KEY: your-api-key"
